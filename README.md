# Calculadora de Pontos TxFlow (não oficial)

- `public/index.html`: a calculadora.
- `api/og.js`: gera o card de cada resultado (`/api/og?v=250000`).
- `api/share.js` (servido em `/s?v=...`): link que vai no post do X; mostra o card e abre a calculadora.

Publicar: `npx vercel` (primeira vez) e `npx vercel --prod`.
